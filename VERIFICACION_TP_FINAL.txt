Base de datos
-------------
Al iniciar sesión, la aplicación crea la tabla Usuario si no existe.
Al abrir Productos, agrega el campo Imagen si todavía no existe.
También se actualizó Vistas\BaseDatos\CrearTablas.sql.

Prueba final en Visual Studio 2010
----------------------------------
1. Abrir LPOOII_GRUPO13.sln.
2. Ejecutar Build > Clean Solution.
3. Ejecutar Build > Rebuild Solution.
4. Confirmar 0 errores.
5. Probar los seis puntos antes de entregar.

Importante
----------
El paquete no incluye las carpetas bin y obj porque Visual Studio las genera
automáticamente al compilar.
